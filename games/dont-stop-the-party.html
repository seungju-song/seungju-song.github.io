Don't Stop the Party

Solo Developer — Game Jam

A hyper-casual arcade game I designed and built from scratch in a single week for the university game jam, on a custom C++ engine on top of Raylib. Every design call, from mechanic to pacing, was mine under the deadline.

Key Features

  • Random enemy spawns keep every run unpredictable
  • Score-driven runs with a saved high-score ranking
  • Screen shake, confetti, and spotlight sweeps for hit feedback
  • Minimal controls (movement + one action button), built for one-week jam judging

My Role

Solo, in one week — I owned every part of it:

  • Core loop design — movement, enemy spawns, scoring
  • Engine programming — the custom C++/Raylib engine underneath it
  • Art and sound, done myself under the deadline
  • Pacing, difficulty, and feedback — every call was mine to make and live with

Controls

  • W / S — navigate menus
  • A / D — steer (you always move forward)
  • Space (hold) — slow down to aim
  • Enter — fire your party popper
  • R — restart
Core Loop

Fire party poppers at the targets scattered around the map as you glide past — land the shot and you keep going, miss it once and the run ends right there.

Why

The jam's theme was "One Time Use." I swapped the usual gun for a party popper to work around DigiPen's game jam rule against depicting killing, and built that same one-time-use idea into every throw itself: miss the one shot you've lined up, and the run ends on the spot.

Gameplay

Design: Speed Is the Risk Dial

Every number below is pulled straight from the shipped C++ — a one-week jam didn't leave time for a separate design doc, so the source is the design doc.

The Loop
Speed Is the Risk Dial

Your one movement stat ranges 200–500: hold Space to brake toward 200, let go to climb toward 500 at 100/s.

It's also the score multiplier — braking to aim trades away the bonus you'd get for staying fast.

Enemies Patrol, They Don't Hunt

Each of the 50 enemies just shuffles back and forth within 400px of its spawn point — no chase AI at all.

The challenge is reading patrol lines and closing the distance yourself, not reacting to pursuit.

The Risk
The Popper Doesn't Travel

A throw is a fixed 60px hitbox that lasts 0.3s right where you fired it — it never actually leaves your position.

"Aiming" means standing on top of an enemy before you commit.

One Miss Ends the Run

If that 0.3-second window closes without a hit, the run is over — no second popper, no retry.

Every throw carries the jam's "One Time Use" theme all the way into the scoring loop.

Metric Value
Speed range200–500 units/sec
Score per hit500 at min speed, 1,200–1,500 above it
Popper hit window0.3s · 60px
Enemies / patrol radius50 · 400px

Cross the min-speed threshold by a hair and the payout jumps from 500 to 1,200+ — braking for an easier shot means giving that up.

Enemy.cpp

DigiPen's jam rules banned depicting killing, so getting hit doesn't destroy an enemy — it drops them into a 5-second "dancing" state (spinning in place, tinted red) before they respawn somewhere new on the map.

Game.cpp

The jam theme was "One Time Use." Each party-popper throw is that one-time use: land it on an enemy and your popper recharges (plus a speed-scaled score bonus); let it fizzle out without hitting anything, and the run ends right there.

Game.cpp Cleaned up
// Named the magic numbers and pulled the score formula into its own
// function — same result as the original inline ternary.
constexpr int kMissHitScore = 500;    // hit while at/under min speed: the "safe" floor
constexpr int kHitScoreBase = 1000;   // hit while above min speed: the risk payoff
constexpr int kSpeedScoreStep = 10;   // +10 score per 10 units of speed above the base

int ScoreForHit(float hero_speed, float min_speed)
{
    if (hero_speed <= min_speed) return kMissHitScore;
    return kHitScoreBase + ((int)hero_speed / kSpeedScoreStep) * kSpeedScoreStep;
}

// ...

if (CheckCollisionRecs(popper.GetHitbox(), enemy.GetHitbox()))
{
    popper.SetHit();
    enemy.GotHit();
    hero.GetPopper();
    score += ScoreForHit(hero.GetSpeed(), hero.GetMinSpeed());
    // ...
    break;
}

// ...

for (int i = partyPoppers.size() - 1; i >= 0; i--)
{
    if (partyPoppers[i].IsActive()) continue;

    if (!partyPoppers[i].DidHit())
    {
        UpdateRanking(); // the popper's 0.3s window closed with nothing hit: run over
        return;
    }
    partyPoppers.erase(partyPoppers.begin() + i);
}
